# 第三方服务托管 v0.1.1

需要 **SoulBot v2.0.4 或更新版本**。在“插件市场”下载本文件夹，核对并启用后，点击“配置参数”，下方提供服务管理面板。

统一管理六个前台进程配置：NapCat、ComfyUI、meme-generator、本地 TTS、本地 LLM，以及自定义服务。提供启动、停止、重启、端口状态、HTTP 能力探测、详细信息、官方指引与脱敏日志。模型只能调用只读状态工具，不能启动或停止进程。

## 配置与使用

1. 按服务官方文档自行完成安装、独立虚拟环境和模型准备。插件不静默下载模型、不安装系统服务、不执行安装脚本。
2. 用“查找配置项”筛选所需服务。填写该服务的**可执行文件绝对路径**、**工作目录绝对路径**、**JSON 参数数组**及实际监听端口，开启“允许托管”并保存。
3. 环境变量用私密 JSON 对象保存，例如 `{"OLLAMA_HOST":"127.0.0.1:11434"}`；不要把 Token 写入普通参数或命令行。密钥留空保留，清除须勾选。
4. 在“插件服务管理”查看服务列表，选择启动并确认。参数修改仅影响下次启动；运行中仍显示原来进程的检测端口。
5. 模型/生图/TTS 的业务配置仍在 SoulBot 对应页面保存；NapCat 协议和扫码登录仍在 NapCat 原生 WebUI 管理。服务托管不会覆盖这些配置。

| 服务 | 可执行文件与参数示例 | 业务配置/说明 |
| --- | --- | --- |
| NapCat | 已安装的前台启动程序；Linux 可使用 `/bin/bash` 与 `["/绝对目录/前台启动脚本.sh"]` | [官方安装与 Shell 入口](https://napneko.github.io/guide/boot/Shell)。QQ 登录由用户完成。不要使用启动后立即退出的 `open`、`start`、`screen -dm` 等包装命令。 |
| ComfyUI | 安装目录 `.venv/bin/python`，`["main.py","--listen","127.0.0.1","--port","8188"]` | [官方手动安装](https://docs.comfy.org/installation/manual_install)。按硬件安装 PyTorch 和模型；不能用 SoulBot 的虚拟环境替代其独立环境。 |
| meme-generator | 独立环境中的 `meme`，`["run"]` | [上游项目](https://github.com/MemeCrafters/meme-generator)；本插件核对过 0.1.14 的 CLI/API。服务端口与上游 config.toml 一致。SoulBot 内置托管器已运行时，不要再启动同一服务。 |
| 本地 TTS | 已安装服务的实际前台入口，按其文档填写参数 | 可使用 [Kokoro-FastAPI](https://github.com/remsky/Kokoro-FastAPI) 等 OpenAI 兼容服务；各项目入口不同，不提供未经验证的通用启动命令。 |
| 本地 LLM | 本机 `ollama` 绝对路径，`["serve"]` | [Ollama CLI](https://docs.ollama.com/cli)。已由桌面端或系统服务运行时只读观察，不重复启动；其他推理框架请改为其实际入口。 |
| 自定义服务 | 管理员明确配置的前台程序和 JSON 参数 | 无任意模型命令入口，不解析 Shell 拼接语法。 |

Windows 用实际 `.exe` 路径；`.bat/.cmd` 入口须由管理员按对应程序文档配置 `cmd.exe` 参数。Windows 仅能保证停止直接持有的进程，未实现 Job Object 对任意后代进程的接管；不要使用会分离后台进程的启动器。macOS/Linux 对仍持有的前台子进程使用独立进程组停止。

## 状态与生命周期

- 允许托管和启动分开；安装、启用、保存配置、宿主重启均不自动启动服务。
- 同服务重复点击启动幂等；其他服务占用端口或旧 PID 归属不明时拒绝创建重复实例。
- 外部已启动的服务标记为“外部服务在线”，不会接管、停止或重启。旧 PID 文件不构成杀进程授权。
- 启动超时显示“启动中”，保留正在加载模型的进程。刷新查看，不自动重试。
- 停用插件或宿主正常关闭时，尝试停止本次持有的服务并记录退出码。宿主崩溃后若进程仍在，显示归属待核对，需要管理员人工检查；不会凭旧 PID 文件终止进程。
- 端口可达不代表 QQ 已登录、模型已加载或语音可合成；详情中的 HTTP 状态/可识别版本单独显示。NapCat 认证页面不会被绕过。
- 不提供无限自动重启。当前版本只提供手动启动和重启，避免模型下载、登录窗口或反复崩溃形成循环。

运行数据位于实例 `data/plugins/service_host/`。状态和日志权限为 0600，日志单服务最多 1MiB，页面只读取最近 16KiB。配置环境变量在采集时脱敏，并处理跨读取块的完整行；仍请勿让第三方程序输出凭据。子进程只继承基本系统环境，不继承 SoulBot API Key。备份不包含进程记录和日志，不据此恢复或重放进程。

Python 插件为当前系统用户权限下的受信任代码，**不是操作系统沙箱**。可执行文件与参数只能由管理员保存；管理操作不会变成模型工具。

## 验证范围

使用独立临时真实进程验证重复启动、重启、停止、异常退出、超时取消、外部端口保护、旧 PID 保护、宿主停用清理和日志脱敏。NapCat 与 ComfyUI 可用性按本机实际探测记录；不把临时进程测试冒充所有上游软件、GPU 或 Windows 的完整验收。
